# BlobInfra
### Self-Hosted Minecraft Server Infrastructure

BlobInfra is a Raspberry Pi-powered hosting project built to keep our Minecraft world, **BloblandSMP**, running independently.

The goal of the infastructure: build a server we fully own and control, automate its maintenance, and preserve our Minecraft world for years to come.

The project combines hardware configuration, Linux server administration, automated GitHub backups, software updates, and remote server management into a single self-hosted system.

### Key Features
**Self-Hosted Infrastructure:** Raspberry Pi hosting with full control over server configuration and world files.
**Automated Backups:** Scheduled scripts to preserve world data through GitHub.
**Server Maintenance:** Automated update and maintenance workflows.
**Remote Management:** Tools for monitoring and administering the server remotely.
**Long-Term Preservation:** Designed to keep BloblandSMP accessible and its world data recoverable for years.

### Our Mission
We want BloblandSMP to outlive the hardware it runs on. By building an independent, maintainable hosting system, we're creating infrastructure that can evolve, migrate, and preserve our world for future generations.
